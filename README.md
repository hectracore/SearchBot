# 🔍 ProSearchBot

> A powerful, feature-rich Telegram Auto Filter & Media Search Bot built with **Pyrogram** and **MongoDB**.

ProSearchBot helps Telegram channel admins automatically filter and deliver media files to users with advanced features like AI-powered spell check, IMDB metadata, online streaming, premium membership management, and much more.

## ✨ Key Features
- 🤖 AI Spelling Check & Smart Search
- 🎬 IMDB Integration with poster support
- 📺 Online Streaming & Fast Download
- 🔐 Force Subscribe (Multi FSub support)
- 💎 Premium Membership Management
- 🔗 Custom Shortlink Support (All websites)
- 📂 Auto & Manual File Filtering
- 📡 Auto Index (files above 2GB supported)
- 🌐 Inline Search
- 📢 User & Group Broadcast
- 🔄 Referral & Redeem Code System
- 🗑️ PreDVD & CamRip Auto Delete
- 🛡️ File Protect & Forward Restriction
- ⚙️ Settings Menu per Group
- 🌅 Auto Greetings (Morning/Evening/Night)
- And much more...

## 🛠️ Built With
- [Pyrogram (Pyrofork)](https://github.com/pyrogram/pyrogram)
- MongoDB / Motor (Async)
- aiohttp, Jinja2
- Google Gemini AI, Bard
- IMDB / Cinemagoer
- yt-dlp, Instaloader
